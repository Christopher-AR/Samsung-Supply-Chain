# Samsung-Supply-Chain

Samsung Supply Chain & Logistic Dashboard


Overview

This repository contains a conceptual or template design for a Supply Chain & Logistic Dashboard branded by Samsung. The dashboard provides a comprehensive view of global operations, tracking key performance indicators (KPIs) across suppliers, inventory, shipments, and customer data.


Key Metrics (KPIs)


The dashboard tracks several critical high-level business metrics:

Gross Revenue: 186.86M

Total Revenue: 176.94M

Total Profit: 48.56M

Profit Margin: 27.44%

Perfect Order Rate: 75%

Total Shipments: 8K


Dashboard Sections

1. Supplier Information
   
Order QTY: 129K

Avg Lead Time: Analyzes supplier performance, identifying those with the best (lowest) lead times, currently showing a range between 9 and 12 days.

3. Inventory (Manufacturer Information)
   
Inventory Value: 160K

Stock by Product: A bar chart visualizing inventory value across different product lines, ranging from 7K to 25K.

5. Shipment Information
   
Shipment Quantity: 3M

Total Delay Shipments: Identifies carriers with the most delays. The data shows a range of 51 to 87 delayed shipments across various carriers.

7. Customer Information
   
Total Delivered QTY: 187K

Revenue by Customer: A breakdown of revenue contributions from top customers, with values ranging from 3220M% to 3675M% (likely representing scaled or indexed values).

Visualizations

The dashboard utilizes:

KPI Cards: For quick snapshots of primary data points.

Horizontal Bar Charts: Used for comparative analysis of lead times, inventory levels, shipment delays, and customer revenue.

Progress Rings: Providing visual cues for quantities like Order QTY and Inventory Value.

Tech Stack

Data Visualization: Power BI Desktop


Data Processing: Power Query Editor, SQL, DAX, Data Modeling
